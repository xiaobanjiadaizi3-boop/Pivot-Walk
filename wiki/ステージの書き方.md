# ステージの書き方

ステージは、名前とマップ（文字列の配列）で書きます。

```js
{ name: 'ステージ名', map: [
  '#######',
  '#AB...#',
  '#.r7..#',
  '#..[CG][CG].#',
  '#######',
]},
```

- 1文字が1マスです。
- `[ ]` でくくると、1マスに複数の記号を書けます（[[ギミックの重ね方]]）。くくった中は1マスとして数えます。
- 行ごとのマスの数がそろっていなくても、足りない分は壁として扱います。
- まわりは壁で囲むのがおすすめです。

## 記号一覧

| 記号 | 種類 | 意味 |
|---|---|---|
| `#` | 地形 | 壁 |
| `.` | 地形 | 床 |
| `r` `7` `L` `J` | 地形 | 三角（埋まっている角: 左上・右上・左下・右下） |
| `^` `v` `>` `<` | 地形 | 山（▲▼▶◀） |
| `A` | ギミック | 足A（赤）の初期位置 |
| `B` | ギミック | 足B（青）の初期位置 |
| `G` | ギミック | ゴール |
| `R` | ギミック | A専用ゴール |
| `U` | ギミック | B専用ゴール |
| `O` | ギミック | 45°アイテム |
| `C` | ギミック | 崩れる床 |
| `S` | ギミック | スイッチ |
| `D` | ギミック | 扉（最初は閉） |
| `d` | ギミック | 扉（最初は開） |
| `P` | ギミック | 塗りマス |

詳しい効果は [[ブロック一覧]] を見てください。

## 必要なもの

- `A` と `B` が1つずつ、上下左右に隣り合っていること
- ゴール（`G` `R` `U`）か塗りマス（`P`）が1つ以上あること

## ゲームに入れる

ゲーム本体（`game` ブランチ）の `index.html` にある `STAGES` 配列に、上の形で追加します。
ステージエディタの「書き出し」を使うと、この形のテキストが出ます。

起動時にソルバーが全ステージを調べ、ブラウザのコンソールに「ステージ番号: 最短○手」を出します。解けないステージや、最短ルートが2通り以上あるステージは警告が出ます。
