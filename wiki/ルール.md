# ルール

## 駒

駒は赤い足（足A）と青い足（足B）の2つの足でできています。
2つの足はいつも隣り合っていて、縦か横に並んでいます（[[ブロック一覧]] の45°アイテムを取ると斜めに並ぶこともあります）。

## 動かし方

1手で、どちらか片方の足を軸にして、もう片方の足を90°回します。
1手の候補は「軸2通り × 回す向き2通り」の最大4つです。スライドやジャンプはできません。

画面では、動かせる先のマスが薄く光ります。マスの中の丸の色は、どちらの足が動くかを表します。
1つのマスに2通りの動き方がある場合は、タップすると色の丸が2つ出るので、動かしたい足の色を選びます。

## 回転中に通るマス

回っている足は、軸の足の斜め隣のマスをかすめて通ります。

```
通るマス C = 動く足の元の位置 + 行き先 − 軸の足の位置
```

- 行き先に乗れないとき（壁・三角・山・閉じた扉・穴・盤面の外）は回れません。
- 通るマス C が壁や閉じた扉のときは回れません。
- C が三角や山のときは、向きによって通れるかどうかが変わります（[[ブロック一覧]]）。
- C が穴のときは通れます（上をかすめるだけなので）。

## クリア条件

足ごとに、乗るべきマスが決まります。

1. その足専用のゴール（足Aなら R、足Bなら U）があるステージでは、専用ゴールに乗る
2. 専用ゴールがなく、共通のゴール G があるステージでは、G に乗る
3. どちらもない足は、どこにいてもよい

たとえば R だけがあるステージは「足Aが R に乗ればクリア」です。

塗りマス（P）があるステージでは、すべての P を踏むことも必要です。ゴールと塗りマスの両方があるときは、両方を満たすとクリアです。

## 戻す・リセット

- 「戻す」で1手前に戻ります。
- 「リセット」で最初からやり直します。
- 一度崩れた床や取ったアイテムも、戻す・リセットで元に戻ります。
