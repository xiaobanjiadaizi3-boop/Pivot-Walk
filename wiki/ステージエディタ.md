# ステージエディタ

`edited` ブランチの `index.html` を開くと、エディタから始まります。

## 置き方

- 下のパレットから部品を選び、盤面のマスをタップするか、なぞって置きます。
- **地形**（壁・床・三角・山）は、マスの中身を置き換えます。「床」はそのマスのギミックも消すので、消しゴムとして使えます。
- **ギミック**（ゴール・アイテム・崩れる床・塗りマス・スイッチ・扉）は、床の上に重なります。
  - 同じギミックがすでにあるマスをタップすると外れます。
  - ゴール同士・扉同士は入れ替わります。
  - 地形の上に置くと、そのマスは床になってから置かれます。
- **足A・足B** は、置いたマスに移動します。
- 幅・高さの「−」「＋」で盤面の大きさを変えられます（右と下が増減します）。

## ボタン

| ボタン | 動き |
|---|---|
| ステージを開く | 組み込みステージや保存したステージを読み込んで編集する |
| 新規 | 空のステージを作る |
| テスト | 今のステージをその場で遊ぶ（「エディタへ」で戻る） |
| 検証 | ソルバーで最短手数と最短ルートの数を調べる。ルートが1通りなら緑で表示 |
| 保存 | このブラウザの中に保存する |
| 削除 | 保存したステージを消す |
| 書き出し | ゲームの `STAGES` に貼れるテキストを出す |
| 読み込み | 書き出したテキストやマップの行を貼り付けて開く |
| 取り消し | 1つ前の編集に戻す |
| 全消去 | 外周を壁、中を床にする |

## 注意

- 「保存」はそのブラウザの中だけに残ります。ゲーム本体に入れるには「書き出し」のテキストを使ってください。
- 検証の「最短ルートの数」は、同じ2×2の中を右回り・左回りするだけの違いは同じルートとして数えます。
