# ギミックの重ね方

1マスには、地形1つと、ギミックをいくつでも重ねられます。

## 決まり

- ギミックは **床の上** にだけ置けます。壁・三角・山の上には置けません。
- 同じ種類のギミックは1マスに1つまでです。
  - ゴール（`G` `R` `U`）は、どれか1つ
  - 扉（`D` `d`）は、どちらか1つ
- 足の初期位置（`A` `B`）も重ねられます。ただし A と B を同じマスには置けません。

## 効果の順番

足が乗ったときは、そのマスのギミックの効果がすべて起きます。順番は次のとおりです。

1. 45°アイテムを取る
2. 塗りマスが塗られる
3. スイッチで扉が切り替わる

足が離れたときは、崩れる床が穴になります。

## 組み合わせの例

| 書き方 | 意味 |
|---|---|
| `[CG]` | 崩れる床のゴール。ゴールに乗った足を動かすと崩れる |
| `[CP]` | 崩れる床の塗りマス。一度しか踏めない |
| `[SP]` | スイッチ兼塗りマス |
| `[DP]` | 扉の上の塗りマス。扉が開いているときにしか塗れない |
| `[Sd]` | 扉の上のスイッチ。乗ると扉が切り替わって足の下で閉じてしまうので、実際には乗れない（最初からここに足を置くことはできる） |
| `[OC]` | 崩れる床の上のアイテム |
| `[AP]` | 塗りマスの上から足Aが始まる（最初から塗られている） |
| `[RC]` | 崩れる床のA専用ゴール |

## 注意

- 閉じた扉は、ほかのギミックより優先されます。閉じている間は、そのマスのゴールや塗りマスにも乗れません。
- 崩れて穴になったマスのギミックは、もう使えません（穴には乗れないため）。
