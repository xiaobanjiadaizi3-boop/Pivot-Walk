# ブロック一覧

マスは「地形」と「ギミック」でできています。

- **地形**: 1マスに1つ。壁・床・三角・山。
- **ギミック**: 床の上に置くもの。1マスに複数重ねられます（[[ギミックの重ね方]]）。

表の「記号」は [[ステージの書き方]] で使う文字です。

## 地形

| 記号 | 名前 | 足が乗れる | 回転で通過（通るマス C として） | 斜めの姿勢で通過 |
|---|---|---|---|---|
| `#` | 壁 | × | × | × |
| `.` | 床 | ○ | ○ | ○ |
| `r` `7` `L` `J` | 三角 | × | 向きによる（下記） | × |
| `^` `v` `>` `<` | 山 | × | 向きによる（下記） | 向きによる（下記） |

### 三角（直角三角形）

マスの対角線で半分が埋まっています。記号は埋まっている角の位置です。

| 記号 | 埋まっている角 |
|---|---|
| `r` | 左上 ◤ |
| `7` | 右上 ◥ |
| `L` | 左下 ◣ |
| `J` | 右下 ◢ |

- 回っている足は、通るマスのうち **軸の足に近い角** をかすめます。
- そのため、**斜めの面が軸の足の側を向いているとき**（埋まっている角が軸の足と反対側にあるとき）だけ通れます。
- 斜めの姿勢のまま回るときは、どの向きでも通れません。

### 山（山形の三角形）

底辺がマスの1辺にあり、頂点がマスの中心にある三角形です。記号は頂点の向きです。

| 記号 | 形 | 底辺の位置 |
|---|---|---|
| `^` | ▲ | 下の辺 |
| `v` | ▼ | 上の辺 |
| `>` | ▶ | 左の辺 |
| `<` | ◀ | 右の辺 |

- 頂点側にある2つの角のどちらをかすめる場合も通れます（直角三角形は1方向だけなので、それより通れる向きが多い）。
- 斜めの姿勢のまま回るときは、**底辺が軸の足の側にある**ときだけ通れます。

## ギミック

| 記号 | 名前 | 効果 |
|---|---|---|
| `A` `B` | 足の初期位置 | 足A（赤）・足B（青）が最初にいるマス。AとBは上下左右に隣り合わせる |
| `G` | ゴール | どちらの足のゴールにもなる |
| `R` | A専用ゴール | 足Aのゴール |
| `U` | B専用ゴール | 足Bのゴール |
| `O` | 45°アイテム | 下記 |
| `C` | 崩れる床 | 足が離れると穴になる。穴には乗れないが、回転で上をかすめて通ることはできる |
| `S` | スイッチ | 足が乗るたびに、すべての扉が開閉する |
| `D` | 扉（最初は閉） | 閉じている間は壁と同じ。乗れず、通れない |
| `d` | 扉（最初は開） | 開いている間は床と同じ |
| `P` | 塗りマス | 踏むと塗られる。すべて塗るとクリア条件の1つを満たす。最初に足が乗っているマスは塗られた状態から始まる |

### 45°アイテム

- 足が45°回ってアイテムのマスに入ると、アイテムを取ります（アイテムは消えます）。駒は斜めの姿勢になります。
- 斜めの姿勢の間は、斜めのまま90°ずつ回って動きます。途中でかすめるのは、軸の足の上下左右のうち元の位置と行き先にはさまれたマスで、その遠い側の辺に沿って通ります。
- 縦・横の姿勢に戻るには、もう一度アイテムを取る必要があります（45°回って別のアイテムのマスに入る）。
- アイテムのマスには、45°回って入るときだけ入れます。普通の90°回転では入れません。普通の回転で上をかすめることはできます。

### スイッチと扉

- スイッチは「足が乗った瞬間」に切り替わります。乗ったままの足（軸の足）では切り替わりません。
- 扉の上に足があるときに、その扉が閉じる手は打てません。
