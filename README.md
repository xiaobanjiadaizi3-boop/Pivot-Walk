# Pivot Walk

2つの足（赤と青）を交互に回して進むパズルゲームです。スマホの縦持ちで遊べます。

| ブランチ | 中身 |
|---|---|
| `game` | ゲーム本体（`index.html` を開くと遊べます） |
| `edited` | ステージエディタ（テストプレイ付き） |

## ルール

### 駒

駒は赤い足（足A）と青い足（足B）の2つの足でできています。
2つの足はいつも隣り合っていて、縦か横に並んでいます（[ブロック一覧](#ブロック一覧) の45°アイテムを取ると斜めに並ぶこともあります）。

### 動かし方

1手で、どちらか片方の足を軸にして、もう片方の足を90°回します。
1手の候補は「軸2通り × 回す向き2通り」の最大4つです。スライドやジャンプはできません（矢印アイテムを取ったときだけ、形のまま1マスずれます。[ブロック一覧](#ブロック一覧)）。

回転だけで動くと、それぞれの足はいつも市松模様の同じ色のマスに乗ります（1手で斜め隣のマスへ動くため）。足のいる色を変えられるのは、45°アイテムと矢印アイテムだけです。

画面では、動かせる先のマスが薄く光ります。マスの中の丸の色は、どちらの足が動くかを表します。
1つのマスに2通りの動き方がある場合は、タップすると色の丸が2つ出るので、動かしたい足の色を選びます。

### 回転中に通るマス

回っている足は、軸の足の斜め隣のマスをかすめて通ります。

```
通るマス C = 動く足の元の位置 + 行き先 − 軸の足の位置
```

- 行き先に乗れないとき（壁・三角・山・閉じた扉・穴・盤面の外）は回れません。
- 通るマス C が壁や閉じた扉のときは回れません。
- C が三角や山のときは、向きによって通れるかどうかが変わります（[ブロック一覧](#ブロック一覧)）。
- C が穴のときは通れます（上をかすめるだけなので）。

### クリア条件

足ごとに、乗るべきマスが決まります。

1. その足専用のゴール（足Aなら R、足Bなら U）があるステージでは、専用ゴールに乗る
2. 専用ゴールがなく、共通のゴール G があるステージでは、G に乗る
3. どちらもない足は、どこにいてもよい

たとえば R だけがあるステージは「足Aが R に乗ればクリア」です。

塗りマス（P）があるステージでは、すべての P を踏むことも必要です。ゴールと塗りマスの両方があるときは、両方を満たすとクリアです。

### 戻す・リセット

- 「戻す」で1手前に戻ります。
- 「リセット」で最初からやり直します。
- 一度崩れた床や取ったアイテムも、戻す・リセットで元に戻ります。

## ブロック一覧

マスは「地形」と「ギミック」でできています。

- **地形**: 1マスに1つ。壁・床・三角・山。
- **ギミック**: 床の上に置くもの。1マスに複数重ねられます（[ギミックの重ね方](#ギミックの重ね方)）。

表の「記号」は [ステージの書き方](#ステージの書き方) で使う文字です。

### 地形

| 記号 | 名前 | 足が乗れる | 回転で通過（通るマス C として） | 斜めの姿勢で通過 |
|---|---|---|---|---|
| `#` | 壁 | × | × | × |
| `.` | 床 | ○ | ○ | ○ |
| `r` `7` `L` `J` | 三角 | × | 向きによる（下記） | × |
| `^` `v` `>` `<` | 山 | × | 向きによる（下記） | 向きによる（下記） |

#### 三角（直角三角形）

マスの対角線で半分が埋まっています。記号は埋まっている角の位置です。

| 記号 | 埋まっている角 |
|---|---|
| `r` | 左上 ◤ |
| `7` | 右上 ◥ |
| `L` | 左下 ◣ |
| `J` | 右下 ◢ |

- 回っている足は、通るマスのうち **軸の足に近い角** をかすめます。
- そのため、**斜めの面が軸の足の側を向いているとき**（埋まっている角が軸の足と反対側にあるとき）だけ通れます。
- 斜めの姿勢のまま回るときは、どの向きでも通れません。

#### 山（山形の三角形）

底辺がマスの1辺にあり、頂点がマスの中心にある三角形です。記号は頂点の向きです。

| 記号 | 形 | 底辺の位置 |
|---|---|---|
| `^` | ▲ | 下の辺 |
| `v` | ▼ | 上の辺 |
| `>` | ▶ | 左の辺 |
| `<` | ◀ | 右の辺 |

- 頂点側にある2つの角のどちらをかすめる場合も通れます（直角三角形は1方向だけなので、それより通れる向きが多い）。
- 斜めの姿勢のまま回るときは、**底辺が軸の足の側にある**ときだけ通れます。

### ギミック

| 記号 | 名前 | 効果 |
|---|---|---|
| `A` `B` | 足の初期位置 | 足A（赤）・足B（青）が最初にいるマス。AとBは上下左右に隣り合わせる |
| `G` | ゴール | どちらの足のゴールにもなる |
| `R` | A専用ゴール | 足Aのゴール |
| `U` | B専用ゴール | 足Bのゴール |
| `O` | 45°アイテム | 下記 |
| `n` `e` `s` `w` | 矢印アイテム | 下記（↑ → ↓ ←） |
| `8` `6` `2` `4` | 一方通行 | 下記（↑ → ↓ ←） |
| `C` | 崩れる床 | 足が離れると穴になる。穴には乗れないが、回転で上をかすめて通ることはできる |
| `S` | スイッチ | 足が乗るたびに、すべての扉が開閉する |
| `D` | 扉（最初は閉） | 閉じている間は壁と同じ。乗れず、通れない |
| `d` | 扉（最初は開） | 開いている間は床と同じ |
| `P` | 塗りマス | 踏むと塗られる。すべて塗るとクリア条件の1つを満たす。最初に足が乗っているマスは塗られた状態から始まる |

#### 45°アイテム

- 足が45°回ってアイテムのマスに入ると、アイテムを取ります（アイテムは消えます）。駒は斜めの姿勢になります。
- 斜めの姿勢の間は、斜めのまま90°ずつ回って動きます。途中でかすめるのは、軸の足の上下左右のうち元の位置と行き先にはさまれたマスで、その遠い側の辺に沿って通ります。
- 縦・横の姿勢に戻るには、もう一度アイテムを取る必要があります（45°回って別のアイテムのマスに入る）。
- アイテムのマスには、45°回って入るときだけ入れます。普通の90°回転では入れません。普通の回転で上をかすめることはできます。

#### 矢印アイテム

| 記号 | 向き |
|---|---|
| `n` | ↑ 上 |
| `e` | → 右 |
| `s` | ↓ 下 |
| `w` | ← 左 |

- 足が乗ると取れて（アイテムは消えます）、すぐに駒が形のまま矢印の向きへ1マスずれます。どの動き方で乗っても取れます。
- ずれる先に乗れないとき（壁・閉じた扉・穴など）や、ずれる先に45°アイテムがあるときは、そのアイテムのマスに入る手は打てません。
- ずれた先のマスの効果も起きます。ずれた先にまた矢印アイテムがあれば、続けてずれます。
- 縦横の姿勢でも斜めの姿勢でも働きます。

#### 一方通行

床に灰色の「≫」が描かれたマスです。記号はテンキーの配置と同じ向きです。

| 記号 | 通れる向き |
|---|---|
| `8` | ↑ 上 |
| `6` | → 右 |
| `2` | ↓ 下 |
| `4` | ← 左 |

- このマスに **入るとき** も **出るとき** も、動く足が矢印の向きに進んでいる必要があります。
  - 普通の回転では足は斜めに動くので、たとえば → の一方通行なら、右上か右下へ動くときだけ入れて、出られます。
  - 矢印と逆向きや、真横（矢印と直角）の動きでは、入ることも出ることもできません。
- 逆向きには戻れないので、一度通ると引き返せない仕掛けになります。
- 軸になっている足（動かない足）には関係ありません。
- 回転中に上をかすめるだけなら関係ありません。
- 矢印アイテムでずれるときも、この決まりが働きます（逆向きにずれる手は打てません）。

#### スイッチと扉

- スイッチは「足が乗った瞬間」に切り替わります。乗ったままの足（軸の足）では切り替わりません。
- 扉の上に足があるときに、その扉が閉じる手は打てません。

## ギミックの重ね方

1マスには、地形1つと、ギミックをいくつでも重ねられます。

### 決まり

- ギミックは **床の上** にだけ置けます。壁・三角・山の上には置けません。
- 同じ種類のギミックは1マスに1つまでです。
  - ゴール（`G` `R` `U`）は、どれか1つ
  - 扉（`D` `d`）は、どちらか1つ
- 足の初期位置（`A` `B`）も重ねられます。ただし A と B を同じマスには置けません。

### 効果の順番

足が乗ったときは、そのマスのギミックの効果がすべて起きます。順番は次のとおりです。

1. 45°アイテムを取る
2. 矢印アイテムを取る（ほかの効果が起きたあとで、矢印の向きにずれる）
3. 塗りマスが塗られる
4. スイッチで扉が切り替わる

足が離れたときは、崩れる床が穴になります。
矢印で縦に並んだまま縦にずれるときなど、足が入れ替わりに乗るマスは「離れた」「乗った」のどちらにも数えません（崩れる床も崩れません）。

### 組み合わせの例

| 書き方 | 意味 |
|---|---|
| `[CG]` | 崩れる床のゴール。ゴールに乗った足を動かすと崩れる |
| `[CP]` | 崩れる床の塗りマス。一度しか踏めない |
| `[SP]` | スイッチ兼塗りマス |
| `[DP]` | 扉の上の塗りマス。扉が開いているときにしか塗れない |
| `[Sd]` | 扉の上のスイッチ。乗ると扉が切り替わって足の下で閉じてしまうので、実際には乗れない（最初からここに足を置くことはできる） |
| `[OC]` | 崩れる床の上のアイテム |
| `[eP]` | 右向き矢印つきの塗りマス |
| `[6G]` | 右向きの一方通行のゴール。右向きに進んで入るしかない |
| `[AP]` | 塗りマスの上から足Aが始まる（最初から塗られている） |
| `[RC]` | 崩れる床のA専用ゴール |

### 注意

- 閉じた扉は、ほかのギミックより優先されます。閉じている間は、そのマスのゴールや塗りマスにも乗れません。
- 崩れて穴になったマスのギミックは、もう使えません（穴には乗れないため）。

## ステージの書き方

ステージは、名前とマップ（文字列の配列）で書きます。

```js
{ name: 'ステージ名', map: [
  '#######',
  '#AB...#',
  '#.r7..#',
  '#..[CG][CG].#',
  '#######',
]},
```

- 1文字が1マスです。
- `[ ]` でくくると、1マスに複数の記号を書けます（[ギミックの重ね方](#ギミックの重ね方)）。くくった中は1マスとして数えます。
- 行ごとのマスの数がそろっていなくても、足りない分は壁として扱います。
- まわりは壁で囲むのがおすすめです。

### 記号一覧

| 記号 | 種類 | 意味 |
|---|---|---|
| `#` | 地形 | 壁 |
| `.` | 地形 | 床 |
| `r` `7` `L` `J` | 地形 | 三角（埋まっている角: 左上・右上・左下・右下） |
| `^` `v` `>` `<` | 地形 | 山（▲▼▶◀） |
| `A` | ギミック | 足A（赤）の初期位置 |
| `B` | ギミック | 足B（青）の初期位置 |
| `G` | ギミック | ゴール |
| `R` | ギミック | A専用ゴール |
| `U` | ギミック | B専用ゴール |
| `O` | ギミック | 45°アイテム |
| `n` `e` `s` `w` | ギミック | 矢印アイテム（↑ → ↓ ←） |
| `8` `6` `2` `4` | ギミック | 一方通行（↑ → ↓ ←） |
| `C` | ギミック | 崩れる床 |
| `S` | ギミック | スイッチ |
| `D` | ギミック | 扉（最初は閉） |
| `d` | ギミック | 扉（最初は開） |
| `P` | ギミック | 塗りマス |

詳しい効果は [ブロック一覧](#ブロック一覧) を見てください。

### 必要なもの

- `A` と `B` が1つずつ、上下左右に隣り合っていること
- ゴール（`G` `R` `U`）か塗りマス（`P`）が1つ以上あること

### ゲームに入れる

ゲーム本体（`game` ブランチ）の `index.html` にある `STAGES` 配列に、上の形で追加します。
ステージエディタの「書き出し」を使うと、この形のテキストが出ます。

起動時にソルバーが全ステージを調べ、ブラウザのコンソールに「ステージ番号: 最短○手」を出します。解けないステージや、最短ルートが2通り以上あるステージは警告が出ます。

## ステージエディタ

`edited` ブランチの `index.html` を開くと、エディタから始まります。

### 置き方

- 下のパレットから部品を選び、盤面のマスをタップするか、なぞって置きます。
- **地形**（壁・床・三角・山）は、マスの中身を置き換えます。「床」はそのマスのギミックも消すので、消しゴムとして使えます。
- **ギミック**（ゴール・45°アイテム・矢印・一方通行・崩れる床・塗りマス・スイッチ・扉）は、床の上に重なります。
  - 同じギミックがすでにあるマスをタップすると外れます。
  - ゴール同士・扉同士は入れ替わります。
  - 地形の上に置くと、そのマスは床になってから置かれます。
- **足A・足B** は、置いたマスに移動します。
- 幅・高さの「−」「＋」で盤面の大きさを変えられます（右と下が増減します）。

### ボタン

| ボタン | 動き |
|---|---|
| ステージを開く | 組み込みステージや保存したステージを読み込んで編集する |
| 新規 | 空のステージを作る |
| テスト | 今のステージをその場で遊ぶ（「エディタへ」で戻る） |
| 検証 | ソルバーで最短手数と最短ルートの数を調べる。ルートが1通りなら緑で表示 |
| 保存 | このブラウザの中に保存する |
| 削除 | 保存したステージを消す |
| 書き出し | ゲームの `STAGES` に貼れるテキストを出す |
| 読み込み | 書き出したテキストやマップの行を貼り付けて開く |
| 取り消し | 1つ前の編集に戻す |
| 全消去 | 外周を壁、中を床にする |

### 注意

- 「保存」はそのブラウザの中だけに残ります。ゲーム本体に入れるには「書き出し」のテキストを使ってください。
- 検証の「最短ルートの数」は、同じ2×2の中を右回り・左回りするだけの違いは同じルートとして数えます。
